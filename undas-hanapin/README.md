# GASERA Undas Special B: Hanapin sa sementeryo

Two 15 s counting puzzles (1080x1920, 30 fps, H.264 + AAC), drawn in code with `make_undas.py`
(PIL + numpy + ffmpeg; run `python make_undas.py kandila` or `mata`).

| File | Puzzle | Answer |
|---|---|---|
| GASERA_undas_kandila.mp4 | Count the candles that get lit | 12 (Kapre's cigar doesn't count) |
| GASERA_undas_mata.mp4 | Count the pairs of eyes | 9 (8 in the cemetery + Kapre) |

# CLAUDE.md — gasera-releases

Public release assets for GASERA reels: final videos and covers that social scheduling (Metricool)
pulls from. **Everything here is public**, so only finished, approved assets go in.

## Rules
- **Only owner-approved finals.** No drafts, previews, raw renders or working files. Those stay in
  the production repo (`folklore-reels`).
- **No secrets, no private data.** No tokens, no `.env`, no email addresses, no fans' names (fans are
  referred to by fan code).
- **Never overwrite or delete a published asset**, because a scheduled post may still point at it.
  A re-made video gets a new filename, and the post is updated to the new URL.
- **Same content rules as the series:** original only (no one else's characters, music or brands),
  kid-safe, and the platform's AI-generated label is turned on when posting.
- Large binaries bloat git history for good. Keep files to the platform's needs (vertical 9:16
  MP4, H.264) and check the size before committing.

## Layout
Not settled yet. When the first assets land, record the folder and naming convention here
(for example `YYYY-MM-DD/<slug>.mp4` + `<slug>.cover.jpg`) so every later release follows it.
